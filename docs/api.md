# Описание API

## login(username, password)

Возвращает `True`, если пара логин-пароль корректна.

## pay(amount, currency)

Проводит платёж и возвращает словарь со статусом операции.

## register(username, password)

Создаёт учётную запись и возвращает словарь с полями `username` и `active`.
